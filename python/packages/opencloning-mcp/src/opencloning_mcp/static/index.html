OpenCloning MCP server

Plan cloning from your AI assistant, and open the result in OpenCloning

This server lets an AI assistant build OpenCloning cloning strategies step by step: import sequences from files, NCBI or Addgene, design primers, and run PCR, restriction, ligation, Gibson, Gateway and other assemblies. Server URL: {{BASE_URL}}/mcp

Your result opens in OpenCloning

When the design is ready, the assistant gives you a link. Click it to open the whole strategy in OpenCloning, where you can inspect and edit every step. If you don't get one, ask: "give me the link to open the strategy in OpenCloning".

Uploading files? Don't paste them in the chat

Pasting a sequence file wastes your tokens and fails for binary files (SnapGene .dna). Instead, ask the assistant for an upload link, upload the files there, and tell it when you're done.

Connect your assistant

Run this once in your terminal:

claude mcp add --transport http opencloning {{BASE_URL}}/mcp

Then start claude and check that it is connected with /mcp.

  1. Open Settings → Connectors (in claude.ai or the desktop app).
  2. Click Add custom connector.
  3. Name it OpenCloning and paste the server URL: {{BASE_URL}}/mcp
  4. Save, and enable the connector in the chat where you want to use it.

Custom connectors are not available on every plan.

  1. Open Settings → Connectors → Advanced and turn on Developer mode.
  2. Create a new connector, paste the server URL {{BASE_URL}}/mcp, and choose no authentication.
  3. In a new chat, enable the connector from the tools menu.

Custom connectors depend on your ChatGPT plan and workspace settings.

In the terminal, start a session with the server as a remote extension:

goose session --with-streamable-http-extension "{{BASE_URL}}/mcp"

To keep it, run goose configure → Add Extension → Remote Extension (Streaming HTTP), name it opencloning and paste the URL. In Goose Desktop: Extensions → Add custom extension, type Streamable HTTP, endpoint {{BASE_URL}}/mcp.

Any client that supports remote MCP servers over HTTP (Cursor, VS Code, Gemini CLI...) works. Add this to its MCP configuration:

{
  "mcpServers": {
    "opencloning": {
      "url": "{{BASE_URL}}/mcp"
    }
  }
}

The file and the name of the url key differ between clients (some use httpUrl or serverUrl, and VS Code uses servers with "type": "http").

Where do my sequences live?

When you use OpenCloning on its own, without MCP, your sequences are not stored anywhere. The MCP server is the exception: the assistant needs somewhere to keep your strategy between steps, so it is stored here.

There are no accounts. When you start working, the server creates a long random token for your strategy and stores the sequences and primers on the server, under that token. Anyone who has the token can read and edit that strategy, but it is 43 characters long and impossible to guess. The token appears in the links the assistant gives you, so don't share those links publicly. Everything is deleted after 30 minutes without use, so open or download your strategy before you leave.
